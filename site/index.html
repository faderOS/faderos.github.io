A clear division of responsibility

One workflow, reusable components.

Prepare the system deliberately, operate the live output explicitly, and keep hardware, control logic and rendering independently maintainable.

01 / THE PANEL

Hardware-first operation

Buttons, lamps, encoders, joystick, T-bar, LCD and segment displays are part of the control model. Sony BKDS-2010 is the first supported panel.

02 / THE CONTROLLER

One surface, three servers

OBS, vMix, ATEM and kavtor adapters share a control model. Three server profiles can stay connected, with mappings and settings in the embedded web interface.

03 / THE PLATFORM

Linux now. Embedded next.

The Linux controller is the working development platform. RP2350 + W5500 is the first embedded target; UART bring-up is available and the full embedded runtime is still being built.
